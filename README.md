# Лабораторные работы: ООП на языке Java и Web-программирование

Выполнил: Рябов И.А., факультет КТИ, группа 5315.

Каждая работа лежит в своей папке: отчёт (`report`) и проект (`project`). Работы курса ООП последовательны: проект каждой
следующей работы дублирует предыдущий и добавляет новое.
