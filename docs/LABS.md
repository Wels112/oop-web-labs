# Разбор по лабораторным работам

Предметная область везде одна: библиотека, читатели и выдачи книг. Запись о выдаче состоит из пяти полей:
читатель, книга, дата выдачи, срок возврата, отметка о возврате. Как запускать, см. [README](../README.md)
и [ECLIPSE.md](ECLIPSE.md).

## Курс «ООП» (Java, Swing)

Каждая работа дублирует предыдущую и добавляет своё, поэтому код лежит одним проектом.
Пакет всего проекта: `edu.java.issues`.

### Лабораторная работа № 1. Среда разработки, консольное приложение

Цель: освоить Eclipse, написать, запустить и отладить консольное приложение.
Что сделано: статический массив целых чисел (дни, на которые выданы книги) упорядочивается методом пузырька
по возрастанию и убыванию, после каждого прохода массив выводится. Комментарии документации есть у всех методов,
Javadoc собирается командой `mvnw javadoc:javadoc`.
Код: `lab1/ArraySort.java`. Запуск: Run As, Java Application, либо меню «Сервис», «Сортировка массива» в окне.
Отладка по методичке (Run/Watch): точка останова в цикле `sort`.

### Лабораторная работа № 2. Интерфейс пользователя

Что сделано: экранная форма «Картотека выдач»: меню, панель инструментов с шестью кнопками-иконками
(сохранить, открыть, добавить, изменить, удалить, печать), таблица выдач в прокручиваемой области,
панель поиска (список читателей, поле названия книги, кнопки), строка состояния, область журнала.
Компоновка: `BorderLayout` для окна, `JSplitPane` для таблицы и журнала, `JToolBar`, `JMenuBar`.
Код: `ui/IssueListForm.show()`.

### Лабораторная работа № 3. Обработка событий

Что сделано: слушатели `ActionListener` (все кнопки), `ItemListener` (выбор читателя: в строке состояния
число его выдач), `MouseAdapter` (двойной щелчок по строке открывает карточку выдачи), `WindowAdapter`
(закрытие окна пишется в журнал). Слушатели оформлены анонимными классами с Javadoc.
Код: `ui/IssueListForm.addListeners()`.

### Лабораторная работа № 4. Обработка исключений

Что сделано: два собственных исключения. `EmptyQueryException`: поиск без условий. `ShortNameException`:
название книги из одного символа. Проверка в `IssueRepository.checkQuery`, обработка блоками `catch` в слушателе
кнопки «Поиск». Дополнительно перехватывается стандартное `ArrayIndexOutOfBoundsException` (двойной щелчок
по пустому месту таблицы) и `StorageException` для ошибок файлов.
Как показать: «Поиск» с выбранным «Все читатели» и пустым полем; «Поиск» с названием «А».

### Лабораторная работа № 5. Сохранение и загрузка данных из файла

Что сделано: данные читаются и пишутся в текстовый файл буферизованными потоками (`BufferedReader`,
`BufferedWriter`), кодировка UTF-8, на каждую запись пять строк. Выбор файла стандартным окном `FileDialog`.
Файл с данными: `data/issues.txt`. Код: `io/TextIssueStorage.java`.
Как показать: кнопка «Сохранить» (имя файла `.txt`), удалить запись, кнопка «Открыть» и выбрать тот же файл.

### Лабораторная работа № 6. Обработка XML-документов

Что сделано: структура XML-документа (`<issues>`, внутри `<issue>` с полями), построение документа через DOM
и запись преобразователем `Transformer`, чтение и разбор через `DocumentBuilder`. Те же кнопки «Открыть»
и «Сохранить» работают с XML, если выбран файл `.xml`. Разбор защищён: DTD и внешние сущности отключены.
Файл: `data/issues.xml`. Код: `io/XmlIssueStorage.java`.

### Лабораторная работа № 7. Отчёты в форматах PDF и HTML

Что сделано: два шаблона JasperReports по структуре XML из работы № 6 (выборка `/issues/issue`):
`issues_pdf.jrxml` (плоская таблица A4, итоговая строка) и `issues_html.jrxml` (альбомная страница,
группировка по читателям, красным выделены невозвращённые книги). PDF строится через `JRPdfExporter`,
HTML через `HtmlExporter`. Шрифт DejaVu Sans встроен, поэтому кириллица в PDF читается.
Как показать: кнопка с принтером, откроются оба файла из `reports/out/`.
Код: `report/IssueReportBuilder.java`, шаблоны в `src/main/resources/reports/`.
Замечание: вместо визуального дизайнера iReport (устарел) шаблоны написаны как JRXML вручную, формат тот же.

### Лабораторная работа № 8. Многопоточные приложения

Что сделано: три потока. «Загрузчик» читает XML в хранилище. «Редактор» ждёт загрузчика, отбирает
невозвращённые книги, сортирует по сроку и записывает XML для отчёта. «Построитель» ждёт редактора
и строит HTML-отчёт. Синхронизация: общий монитор, `wait()` и `notifyAll()` в цикле по условию,
`join()` в основном потоке. Потоки запускаются в обратном порядке, чтобы ожидание было видно.
Как показать: меню «Потоки», «Запустить конвейер», смотреть строки «жду, пока...» в журнале.
Код: `concurrent/ReportPipeline.java`.

### Лабораторная работа № 9. Модульное тестирование

Что сделано: тесты JUnit 5 на хранилище и поиск (`IssueRepositoryTest`), файлы и отчёты
(`StorageAndReportTest`), конвейер потоков, проверку дат и сортировку (`PipelineAndUtilTest`).
Запуск: `mvnw test` или Run As, JUnit Test. Всего 28 тестов вместе с тестами курса Web.

### Лабораторная работа № 10. Протоколирование

Что сделано: Log4j 2, настройка в `src/main/resources/log4j2.properties`: вывод в консоль и в файл
`logs/issues.log`, формат «время, уровень, поток, класс:метод:строка, сообщение». Сообщения уровней
debug, info, warn, error пишут хранилище, файловые классы, окно, потоки и сервлеты. Журнал виден и в самом
окне (`ui/SwingLogAppender.java`). Исключения пишутся в журнал вместе со стеком вызовов.

## Курс «Web-программирование» (Java, Tomcat, Maven)

### Лабораторная работа № 1. Установка и настройка сервера

Что сделано: Apache Tomcat 10.1 подключён как библиотека (`tomcat-embed`) и запускается из `Launcher`,
отдельная установка не нужна. Порты 8080 (HTTP) и 8443 (HTTPS), кодировка адресов UTF-8.
Как показать: страница «О системе» (версия Tomcat, Servlet API, Java).
Для классического варианта с отдельным Tomcat см. раздел 4 в [ECLIPSE.md](ECLIPSE.md).

### Лабораторная работа № 2. Web-проект на Maven

Что сделано: проект с упаковкой `war`, зависимости и плагины в `pom.xml` (компилятор, war, surefire, javadoc,
dependency). Команда `mvnw package` собирает `target/issues.war`, который можно скопировать в `webapps` Tomcat.
Структура проекта стандартная: `src/main/java`, `src/main/resources`, `src/main/webapp`, `src/test/java`.

### Лабораторная работа № 3. Технология сервлетов

Что сделано: HTML-страница и сервлет `IssueServlet`. Параметры инициализации (`titleKey`, `maxRows`)
заданы в `web.xml`, динамические параметры `reader` и `book` приходят в адресе. Страницу целиком печатает
код сервлета. Весь пользовательский текст экранируется.
Адрес: `/servlet/issues?reader=Иванов Пётр&book=мушк`. Документация: `mvnw javadoc:javadoc`.

### Лабораторная работа № 4. Интернационализация

Что сделано: файлы ресурсов `messages_ru.properties` и `messages_en.properties` (UTF-8), фильтр `LocaleFilter`
выбирает язык по параметру `lang`, затем по сессии, затем по заголовку Accept-Language браузера.
Язык применяется и в сервлете (`ResourceBundle`), и в JSP (`fmt:message`).
Как показать: ссылки RU и EN в шапке сайта.

### Лабораторная работа № 5. Технология JSP

Что сделано: страница `issues.jsp` с директивами, тегами JSTL (`c:forEach`, `c:choose`, `c:out`, `fmt:message`),
объявлением (`<%! %>`, метод склонения слова), скриптлетом (`<% %>`) и выражением (`<%= %>`).
Данные готовит контроллер `IssuesController` и передаёт через `forward`. Страницы лежат в `WEB-INF/views`,
прямой доступ к ним закрыт. Общая шапка подключается директивой `include`.

### Лабораторная работа № 6. Аутентификация и авторизация

Что сделано: страница входа, `LoginServlet`, `LogoutServlet`, фильтр `AuthFilter`. Без входа открыты только
главная, вход и стили. Две роли: библиотекарь меняет данные, читатель только смотрит (сервер отвечает 403,
кнопок в интерфейсе читателя нет). Пароли хранятся как хеш PBKDF2 с солью, после входа создаётся новая сессия,
формы защищены токеном, возврат после входа ограничен адресами внутри сайта.
HTTPS: порт 8443, самоподписанный сертификат, созданный утилитой `keytool` (`conf/keystore.p12`).

### Лабораторная работа № 7. Передача данных между запросами

Что сделано: страница «Выбор читателя» сохраняет выбор в атрибуте сессии и в cookie `lastReader`
(при следующем заходе предлагается прежний выбор), затем делает перенаправление (`sendRedirect`) на список выдач,
который показывает книги выбранного читателя. После добавления, изменения и удаления записи
сообщение об итоге передаётся через сессию и показывается один раз (шаблон «перенаправление после POST»:
обновление страницы не повторяет операцию).

### Лабораторная работа № 8. Разработка web-приложения с использованием GWT

Что сделано: GWT 2.13. Клиентская часть (`gwt/client`) на Java: список читателей, кнопка «Получить список книг»,
диалоговое окно с таблицей, как в методичке. Служба GWT-RPC: интерфейсы `IssueService` и `IssueServiceAsync`,
реализация `gwt/server/IssueServiceImpl`. Компилятор превращает клиент в JavaScript, результат лежит
в `src/main/webapp/gwt-app` (пересборка описана в README). Страница: пункт «GWT» в шапке сайта.

### Лабораторная работа № 9. Модульное тестирование web-приложения

Что сделано: тест сервлета с mock-объектами Mockito (`IssueServletTest`): подмена запроса и ответа,
проверка фильтра по читателю, экранирования, английской локализации, пустого результата.
Плюс `AuthTest`: проверка паролей, ролей и перенаправления на вход без запуска Tomcat.
