# Объединённое приложение

Выполнил: Рябов И.А., факультет КТИ, группа 5315.

Одно приложение с возможностями лабораторных работ ООП 1-10 и Web 1-9 на общем наборе данных «Картотека выдач».
Окно Swing: форма, события, исключения, файлы TXT и XML, отчёты PDF и HTML, потоки, журнал Log4j.
Сайт на встроенном Tomcat (порты 8080 и 8443): сервлет, два языка, JSP, вход по ролям, сессия и cookie, GWT.
Запуск: `run.bat` (Windows) или `./run.sh`. Вход на сайт: librarian / lib123 или reader / read123.
